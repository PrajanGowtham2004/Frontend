CSS Concepts

1. What is CSS?

Definition: CSS (Cascading Style Sheets) is used to style and design HTML webpages.

Purpose: Controls colors, fonts, spacing, layouts, and animations.

2. Types of CSS

Inline CSS: Written inside HTML elements.

Internal CSS: Written inside <style> tag.

External CSS: Written in a separate CSS file.

3. Element Selector

Definition: Selects all elements of a specific tag.

Definition: Selects every element on the page.

Used for resetting margin and padding.

13. z-index

Definition: Controls stacking order of overlapping elements.

Definition: Applies styles when the mouse pointer is placed over an element.
