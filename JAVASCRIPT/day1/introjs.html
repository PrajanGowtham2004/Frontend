JavaScript Basics

1. What is a Variable?

A variable is a container used to store data in a program. 

let name = "Prajan";
let age = 21;

2. What is Declaration?

Declaration is the process of creating a variable. 

let age;

3. What is Initialization?

Initialization is the process of assigning a value to a variable. 

let age = 21;

4. What are the Three Keywords Used to Declare Variables?

JavaScript provides three keywords: var, let, and const. 

var a = 10;
let b = 20;
const c = 30;

5. What is the Compiler in JavaScript and What is Its Name?

A compiler converts JavaScript code into machine code. The most popular JavaScript engine is V8. 

Chrome Browser → V8 Engine
Node.js → V8 Engine

6. What are Printing Statements?

Printing statements are used to display output from a program. 

console.log("Hello World");
console.warn("Warning");
console.error("Error");
