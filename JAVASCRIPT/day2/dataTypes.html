A complete overview of Primitive and Non-Primitive Data Types

Primitive Data Types

Primitive data types store a single value and are immutable.

Data Type Example typeof Description
String "Prajan" string Stores text values.
Number 25, 3.14 number Stores integers and decimals.
Boolean true, false boolean Stores logical values.
Undefined let x; undefined Variable declared but not assigned.
Null let x = null; object Represents intentional empty value.
BigInt 123456789n bigint Stores very large integers.
Symbol Symbol("id") symbol Creates unique identifiers.
NaN Number("abc") number Represents invalid number result.

Non-Primitive Data Types

Non-primitive data types can store collections of values.

Data Type Example typeof Description
Object {name:"Prajan"} object Stores key-value pairs.
Array ["JS","Python"] object Stores multiple values.
Function function greet(){} function Reusable block of code.

Quick Summary

Primitive

String, Number, Boolean, Undefined, Null, BigInt, Symbol

Non-Primitive

Object, Array, Function

Important Notes

typeof null → object, typeof NaN → number, Array is also an object.
